## Descrizione

Questo è il repository del mio portfolio personale, progettato per presentare la mia esperienza, competenze, progetti e formazione in modo professionale e accattivante. Il sito è costruito interamente con tecnologie web standard (HTML, CSS e JavaScript) e utilizza solo le librerie essenziali per mantenere prestazioni elevate e facilità di manutenzione.

## 🚀 Setup e Installazione

1. **Clona il repository**:
   ```bash
   git clone https://github.com/tuonome/portfolio.git
   ```

2. **Apri localmente**:
   - Apri il file `index.html` nel tuo browser per visualizzare il sito
   - Oppure utilizza un server locale come Live Server di VSCode

3. **Personalizza i contenuti**:
   - Modifica `index.html` per aggiornare testi e struttura
   - Personalizza gli stili in `css/styles.css`
   - Adatta le funzionalità in `js/main.js`

4. **Deploy su GitHub Pages**:
   - Push delle modifiche sul tuo repository
   - Vai su Settings > Pages e attiva GitHub Pages
   - Seleziona il branch `main` come source

## Come Usare

Il portfolio è strutturato in sezioni navigabili. La navigazione in alto consente di saltare direttamente a ciascuna sezione. Per mobile, è disponibile un menu hamburger che si apre con un tocco.

### Personalizzazione

1. **Informazioni Personali**: Aggiorna nome, titolo e descrizione in `index.html`
2. **Foto Profilo**: Sostituisci `gabriel.jpg` nella cartella `img/` con la tua foto
3. **Esperienze e Progetti**: Modifica le card nelle rispettive sezioni
4. **Skills**: Aggiorna le competenze e i livelli di padronanza
5. **Social Links**: Cambia i link nei pulsanti di contatto e nel footer

### Manutenzione

Per mantenere il sito aggiornato:

1. **Aggiungi nuovi progetti**: Duplica un elemento card esistente nella sezione Projects
2. **Aggiungi nuove esperienze**: Duplica un elemento nella sezione Experience
3. **Aggiorna le competenze**: Modifica o aggiungi elementi nella sezione Skills

## Tecnologie Utilizzate

- **HTML5**: Struttura semantica
- **CSS3**: Styling moderno con CSS custom properties, flexbox e grid
- **JavaScript**: Interattività e animazioni
- **Font Awesome**: Icone
- **Google Fonts**: Tipografia (Poppins)
